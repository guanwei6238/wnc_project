# 報告製作

根據每次要做的報告開一個資料夾，名稱設定為`[報告時間_標題]`

## 使用工具
使用 typst 製作，可以先將常用的功能寫成模板放在根目錄

## 專案
這個計畫的專案在 `../` 如果需要知道目前做到怎麼樣的話可以看這邊

## 輸出檔案
在報告的資料夾內應該要有以下文件
- 原始草稿(`user_draft.md`, `slide_implement.md`)
- 報告原始碼(應該是一個資料夾裡面是 *.typ)
- 報告(只會有一個 `[標題].pdf`)
- 逐字搞
- assert/ (放圖片等資源)

## 報告製作流程
1. 先查證使用者給的草稿在每個技術 or 架構的事實或是可以優化的點
2. 撰寫 `slide_implement.md` 說明每頁要有哪些資料（如果需要截圖等你沒辦法操作的資源可以找 user 處理）的文件
3. 開一個 subagent (sonnet) 照 `slide_implement.md` 把報告做出來
4. 開一個 subagent (opus) 檢查做完的報告是否有依據 `slide_implement.md` 並驗證所有說明的真實性，並輸出一個 markdown 說明驗證了什麼東西。

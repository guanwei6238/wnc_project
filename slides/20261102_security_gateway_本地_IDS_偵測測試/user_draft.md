1. 資料集狀態綜整表：每個 dataset 一列，把目前狀態表示清楚；不用先做完，之後每次更新。

2. 偵測能力：「這些流量被送進去之後，可以被偵測出來嗎？」（alert 對 label，不是 rule 能偵測哪些種類）

使用者 2026-10-30 的要求（原話重點）：

  Benign 上的 alert 只列數字；Suricata 8.0.7 + 當天 ET Open 8.0 的 `full`，`gw_corp` 依 SID 篩；五元組 + 時間對 flow。
- 「根據之前做的數據應該要先對齊才能測試對嗎？」→ CIC-IDS2017、CIC-DDoS2019 先對齊；CICIoT2023 只能檔案層級。

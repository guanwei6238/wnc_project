# 事實查證：資料集可復現性的判斷準則（2026-10-04）

背景：原本 P7 的「三個條件（封包＋標籤＋對應鍵）」是自行推導、綁定 tcpreplay 的標準，使用者要求改用有出處的準則，且不綁定工具。

## 來源（VERIFIED = 讀到原文）
1. ACM Artifact Review and Badging v1.1（2020-08-24）— VERIFIED（Wayback）
   https://www.acm.org/publications/policies/artifact-review-and-badging-current
   - Repeatability：同團隊同設定；Reproducibility："an independent group can obtain the same result using the author's own artifacts"；Replicability：不同團隊自建 artifact
   - Artifacts Available：公開封存庫 + DOI／唯一識別碼（個人網頁不算）
   - Evaluated–Functional：documented、consistent、complete、exercisable
   - Results Reproduced／Replicated：結果在可接受誤差內
2. Wilkinson et al., FAIR Guiding Principles, Scientific Data 3:160018, 2016, doi:10.1038/sdata.2016.18 — VERIFIED
   - F1 持久識別碼、F2 rich metadata、A1 以識別碼經標準協定取回、R1 屬性描述、R1.1 授權、R1.2 provenance、R1.3 社群標準
3. Sharafaldin et al., ICISSP 2018, doi:10.5220/0006639801080116 — VERIFIED
   - 11 項準則（引言）：Attack Diversity、Anonymity、Available Protocols、Complete Capture、Complete Interaction、Complete Network Configuration、Complete Traffic、Feature Set、Heterogeneity、Labelling、Metadata（第 5 節只逐項說明 10 項，無 Anonymity）
   - 出自 Gharib et al., "An Evaluation Framework for Intrusion Detection Dataset", ICISS 2016（Information Science and Security）, doi:10.1109/ICISSEC.2016.7885840（書目 OpenAlex 核對；全文 UNCLEAR）
4. Ring et al., "A survey of network-based intrusion detection data sets", Computers & Security 86:147–167, 2019, doi:10.1016/j.cose.2019.06.005 — VERIFIED（arXiv:1903.02460）
   - 5 類 15 屬性；Public Availability："the quality of data sets can only be checked by third parties if they are publicly available"
   - Labeled 取值含 yes (IDS)、indirect
   - 結論："In order to ensure reproducibility for third parties, we recommend evaluating ... with at least one publicly available data set."
5. Engelen et al., IEEE SPW 2021, doi:10.1109/SPW53761.2021.00009 — VERIFIED
   - 好資料集條件 "(g) reproducible"、"(i) documentation and metadata of data collection"
   - "information about the IP addresses of attackers and victims as well as the time window ... which should allow for reproducibility of the labelling logic"
   - "time frames ... are not precise, therefore we had to tune them to reproduce the labelling"
6. Lanvin et al., CRiSIS 2022, doi:10.1007/978-3-031-31108-6_2 — 僅摘要
   - "labelling correctness is paramount ... but is often considered as the ground truth by practitioners and is rarely verified"
7. Gebru et al., "Datasheets for Datasets", arXiv:1803.09010 — VERIFIED（arXiv 版）
   - §3.4："Was the 'raw' data saved in addition to the preprocessed/cleaned/labeled data?"、"Is the software that was used to preprocess/clean/label the data available?"

## 建議準則（不綁工具）
| 準則 | 出處 |
|---|---|
| 1 原始資料可持久取得、有授權 | ACM Artifacts Available；FAIR F1/A1/R1.1；Ring Public Availability |
| 2 標籤可追溯到原始流量 | Engelen (g)；Ring Labeled；Gebru §3.4；Lanvin |
| 3 產生過程有完整紀錄 | FAIR R1/R1.2；Ring Metadata、Complete Network；Sharafaldin Metadata |
| 4 處理流程可重做（從原始資料重新產生標籤／特徵） | ACM Functional（exercisable）；Gebru §3.4 |
